# Handbook

This repository holds the team handbook: how we plan, build, review and ship.

## Contributing

Open a merge request against `main`. Small fixes can be merged by any maintainer; changes to process docs need one approval from the docs guild.

See [the style guide](docs/style-guide.md) before writing new pages, and [RFC 0042](docs/rfcs/0042-reading-first-reviews.md) for how documentation reviews work.

> [!TIP]
> Install the Galley extension to review documentation changes as rendered articles.
