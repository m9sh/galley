# ADR 0001: Record architecture decisions

## Status

Accepted

## Context

Decisions get made in meetings and threads, and the reasons are lost within a year.

## Decision

Each significant decision gets a short record in `docs/adr/`, numbered and never deleted. A decision that replaces another says so in its status.

## Consequences

Newcomers can read why, not only what. See [writing documentation](../guides/writing-docs.md) for the format.
