# How-to guides

Step-by-step recipes for changes that touch several files. Each lists the files, the order, and how to know you are done. For the reasoning behind the steps, follow the links to the ADRs.

| Guide | When |
| --- | --- |
| [Add a reader setting](add-a-setting.md) | A new choice in **Reading settings** |
| [Add a reading palette](add-a-palette.md) | A new colour set, light and dark |
| [Add a keyboard shortcut](add-a-shortcut.md) | A new key in the reader |
| [Add a GitHub API call](add-a-github-api-call.md) | The reader needs data GitHub's API has and Galley does not fetch yet |
| [Verify a UI change](verify-a-ui-change.md) | Anything that changes what the reader looks like or how it behaves |
| [Validate repository reading](validate-repository-reading.md) | Research sessions for RFC 0049: the repository reader, the project map and notes |

- [store/ARTWORK.md](../../store/ARTWORK.md): regenerating screenshots and artwork.
- [site/README.md](../../site/README.md): the website and pull request demos.
- [Write an ADR](../adr/README.md#how-to-add-one) and [propose an RFC](../rfcs/README.md#how-it-works).
