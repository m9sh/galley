GitHub token · private repositories and comments

Public repositories work without one. For private ones, create a fine-grained token with Contents: read-only and Pull requests: read-only to read. To post comments from the reader, use Pull requests: read and write. It is stored only in this browser.

Open a pull or merge request and press Read. In the reader: J/K changes, [/] files, C clean view, Esc close.
