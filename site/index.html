How do I install it?

Open Galley in the Chrome Web Store, choose Add to Chrome, and confirm Add extension.

Open a GitHub pull request or GitLab merge request, then press Read in the bottom-right corner.

Unpacked Chrome and Firefox builds are also available from GitHub releases.

Which browsers does it support?

Galley is tested in Chrome. The Chrome build can also be loaded in Chromium browsers such as Edge, Brave, and Arc. A Firefox build is available, but hasn’t been tested in Firefox yet. Safari isn’t packaged.

Does it work with private repositories?

Yes. GitLab uses your signed-in session. Private GitHub repositories need a personal access token, saved in the extension. Reading needs read-only Contents and Pull requests access; commenting also needs Pull requests write access.

Self-hosted GitLab and GitHub Enterprise Server can be enabled per site from the extension popup. Read the setup guide ↗

What happens to my documents and comments?

Galley fetches documents from your code host and renders them locally. Comments are sent to GitHub or GitLab when you post. The demo keeps comments in your browser session and never posts to either platform.
